\# NewsHub — News Aggregator



A Python-based news aggregator that brings news from multiple categories into one place, allowing users to browse headlines from Technology, Sports, Business, and World news.



\## Project Overview



NewsHub is a semester project developed for the \*\*Software Construction and Development\*\* course. The goal is to build a simple application that fetches news from an external news API and presents headlines through a user-friendly interface.



The project will be developed incrementally using software engineering principles, Git version control, and collaborative development practices.



\## Objectives



\- Provide news headlines from multiple categories in one place.

\- Allow users to browse news by category.

\- Display relevant article information, such as headlines, sources, publication dates, and images when available.

\- Provide links to original articles for complete news coverage.

\- Practice collaborative software development, requirements engineering, and version control.



\## Planned Features



\- \[ ] Browse Technology news.

\- \[ ] Browse Sports news.

\- \[ ] Browse Business news.

\- \[ ] Browse World news.

\- \[ ] Fetch news from an external news API.

\- \[ ] Display headlines and available article information.

\- \[ ] Open original news articles in a browser.

\- \[ ] Handle API errors and empty results.

\- \[ ] Add keyword-based news search.

\- \[ ] Add a news refresh option.



\## Technologies



\- \*\*Python\*\* — application logic

\- \*\*Flask\*\* — web application framework

\- \*\*HTML and CSS\*\* — user interface

\- \*\*Requests\*\* — HTTP requests to the news API

\- \*\*Git and GitHub\*\* — version control and team collaboration
